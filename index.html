Simulation scope and results

The page reads a saved simulator run. Controls explore that run; they do not rerun the model or estimate a new configuration.

Included All 36 decode layers, selected MoE experts, local KV writes, TP reductions, PP relays, final normalization, LM head and host transfers.

Model boundary Coarse DMA/Tensor/SIMD timing. Simulation descriptors, not executable hardware ISA traces. Host embeddings and sampling, energy, native chiplet execution, expert parallelism and multiple devices are outside this run.

Sources & reproducibility

Official model configuration · Official reference semantics

CAL Figure 2 defines this physical array; Figure 3 defines TP4 / PP4. The 256 GB/s D2D value is interpreted here per port, per direction. Each chiplet's three D2D ports transmit concurrently, and D2D hops do not consume local HBM / NoC bandwidth.

Routing uses deterministic synthetic assignments; each token selects four distinct experts. A supplied routing trace can replace those assignments. All 128 experts remain allocated in FP16, even when idle. The published MXFP4 checkpoint size is not used.
